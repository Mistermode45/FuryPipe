# M5.1 Durable Retention Governance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Compact only complete known M5 terminal lineages into durable tombstones while preserving historical existence and never creating replay authority.

**Architecture:** Add a versioned tombstone record and a bounded internal maintenance coordinator. Compaction runs under RecoveryStore's existing inter-process lock through a new atomic compound primitive, verifies exact lineage, and leaves unresolved or mixed states fail-closed. No public raw mutation primitive is exported.

**Tech Stack:** TypeScript, Node.js, Vitest, existing content-addressed RecoveryStore, existing M5 durable replay coordinator.

**Spec:** `docs/DIRECT_MCP_DURABLE_RETENTION_GOVERNANCE_2026.md`
