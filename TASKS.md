preuves externes/hébergées restent absentes. M15 local (Security CI exporter +

principalement les validations hébergées Provider/OAuth/MCP/OpenClaw/Figma, les
audits/field evidence explicitement externes, la policy GitHub de release et les
actions de release nécessitant une autorisation mainteneur. La préparation RC
locale est automatisée mais ne débloque M19 qu’après toutes les preuves requises
et l’autorisation explicite.
